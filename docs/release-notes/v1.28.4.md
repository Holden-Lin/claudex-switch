# WorkBuddy 不再悄悄改用收费 SG 模型

- 目录里找不到已保存的基础 DeepSeek 时，默认模型、共享设置映射和目录刷新都不再自动改用 Fable 或收费的 `-sg` 模型；启动 Claude 前直接报错并要求选择。明确传入的 `--model …-sg` 或 profile 里的模型仍照用。
- 同名 `-sg` 只在基础模型确实在当前目录里时才隐藏，避免选择器里出现重复项。
- 模型价格按目录原样显示；只有目录明确标为免费时才显示 `x0.00 (free)`，未知价格不再当作免费。
- 新增只读账单核对 `scripts/inspect-workbuddy-billing.ts`：只读计费记录，输出请求 ID、计费模型、额度、客户端和时间，不发聊天请求、不输出提示词和登录头。
- 已知情况：此账号即使在官方 CodeBuddy 里选 x0.00 的基础 DS，也按 SG 计费，原因待官方答复。
