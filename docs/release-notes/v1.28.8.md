# 切换 Codex 账号后能看到其他 ChatGPT 账号的会话

- Codex 0.169 起，新会话只在创建它的 ChatGPT 账号的 `/resume` 中显示。全局切换、`--run` 启动前和 `--run` 退出后，claudex-switch 会让受管账号所建会话在各账号间共享（去掉 `account_scoped` 标记，保留创建者 id）。
- 会话元数据修改不再改变 rollout 首行的字节长度：Codex 的分页历史和 fork 按字节偏移读取，旧版把 `hybaliez` 改成 `openai` 时少 2 字节，恢复后新追加的记录会被跳过。旧版留下的这类偏差会自动补回。
- 同步覆盖 Codex 压缩后的 `.jsonl.zst` 会话。更长的中转 provider 名放不下时，该旧会话保留原 provider，可回到创建它的账号恢复。
- 498 项测试通过；真实 Codex 0.169 下，同步后另一账号的 `/resume` 列表即可看到这些会话。
