# v1.25.0 发布说明

- `list` 的每周额度后面新增本地重置时间：`wk 61% Wed16` 表示每周额度在本地时间周三 16 点重置（按最近整点取整，因服务端常报 15:59:59）。适用于 Claude OAuth、Codex ChatGPT 与 OpenCode 订阅账号；服务端未给重置时间时不显示。`--json` 输出不变（原已含 `weeklyResetsAt`）。

# v1.25.0 release notes

- **Weekly reset time in `list`.** The weekly quota now shows when it resets, in local time: `wk 61% Wed16` means Wednesday 16:00 (rounded to the nearest hour, since providers often report 15:59:59). Applies to Claude OAuth, Codex ChatGPT and OpenCode subscription accounts; omitted when the provider reports no reset time. `--json` output is unchanged (it already includes `weeklyResetsAt`).
