# v1.19.0 release notes

These notes describe the v1.19.0 feature set. Check the [GitHub releases page](https://github.com/Holden-Lin/claudex-switch/releases) for current availability.

- `-run --autoreview on|off` now also works for OpenCode aliases. It sets or clears `CODEX_COMPLETION_REVIEW_DISABLED` for this launch only, which the OpenCode V2 completion-review plugin reads (the plugin runs the same Codex review script as the Codex Stop hook). Without the flag, the caller's environment is inherited as before.
- Claude aliases still reject `--autoreview`. Codex behavior is unchanged.
