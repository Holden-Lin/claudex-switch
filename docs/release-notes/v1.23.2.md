# v1.23.2 发布说明

- 修复通过 claudex-switch 启动 OpenCode V2 后看不到免费模型的问题。API key 与 Console 订阅账号均可在 `/models` 选择原生免费模型，例如 `opencode/deepseek-v4.1-flash-free`。
- Go 模型继续使用所选别名的凭据和路由；免费模型保留原生 OpenCode 路由。依据模型全部价格档位判断是否免费，订阅账号隐藏原生付费及价格未知模型；用户显式禁用的 provider / 模型保持禁用。
- 会话压缩余量同时考虑可切换的免费模型，避免从大窗口 Go 模型切到小窗口免费模型后无限压缩。用户全局配置不变。
- 命令行默认模型仍选 Go，启动 TUI 后用 `/models` 切换免费模型。
