# agy 独立订阅入口与 Claude Code 自动代理

Antigravity（agy / Gemini）、WorkBuddy 和 Cursor 现在按订阅展示，使用 `--cliproxy claudecode` 自动启动 Claude Code 前端。

- `claudex-switch add <alias>` 提供 `Antigravity Subscription — agy (Gemini)`、`WorkBuddy Subscription` 和 `Cursor Subscription`，不再单列「Claude Code · 订阅」组合。
- 保存订阅后提示运行 `claudex-switch <alias> --run --cliproxy claudecode`；也可以直接运行 `claudex-switch agy --run --cliproxy claudecode`，首次完成现有授权流程。
- 旧组合创建的别名继续复用原有登录，支持同一条 `--cliproxy claudecode` 命令；原有 `<alias> -run` 和 `<alias> cc` 仍可使用，无需重新添加账号。
- 沿用现有代理和模型目录实现；中文、英文 README 与订阅接入说明已同步。

验证：522 项测试通过；类型检查、构建与文档链接检查通过。隔离测试订阅已在真实 PTY 中完成选择、保存，并通过 `--cliproxy claudecode --version` 启动真实 Claude Code 2.1.331；未测试厂商模型响应。

当前使用 bun 全局安装的本机，可在本人终端升级：

```bash
bun install -g git+https://github.com/Holden-Lin/claudex-switch.git#v1.29.2
```

升级后添加订阅或启动：

```bash
claudex-switch add my-agy
claudex-switch my-agy --run --cliproxy claudecode
# 或直接使用 agy；首次运行会进入登录流程
claudex-switch agy --run --cliproxy claudecode
```
