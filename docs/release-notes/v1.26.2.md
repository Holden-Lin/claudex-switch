# v1.26.2 发布说明

- 修复 WorkBuddy / Cursor 订阅模型在 Claude Code 中过早压缩。Claude Code 不认识 `deepseek-v4.1-flash` 等模型 ID，统一按 200K 窗口计算；设置 `CLAUDE_AUTOCOMPACT_PCT_OVERRIDE=40` 时约 72K 即压缩，而该模型实际支持 1M。
- 现在按订阅目录报告的窗口为每个模型设置压缩窗口：deepseek-v4.1-flash 1M（40% 时约 392K 压缩），kimi-k2.6 256K，hy3 192K，default-model 176K；`opus` 等档位按其映射模型的窗口计算。不再出现 “doesn't recognize the model … assumes 200k” 警告。
- 不采用模型名加 `[1m]` 的做法：实测 Claude Code 2.1.309 对带 `[1m]` 的未知模型关闭主动压缩，经代理时无法可靠恢复。
- 旧账号无需操作：没有正在运行的会话时，下次启动会重启代理并补齐窗口；仍有会话时，待会话结束后生效。

已用真实 Claude Code 2.1.309 读取生成的配置，逐个模型核对有效窗口；真实 CLIProxyAPI + WorkBuddy 插件端到端脚本通过。
