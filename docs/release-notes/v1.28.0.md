# v1.28.0：代理账号按服务商分组，列表不再显示 CLIProxyAPI

`claudex-switch list`、无参数选择器和 `current` 把通过本机代理运行的账号按服务商单独分组：Antigravity、WorkBuddy（国内版 / 国际版）、Cursor 各自一组，没有该类账号时分组不显示。代理行只保留套餐、运行状态、模型和原有额度格式，不再出现「local CLIProxyAPI」分类或前缀。

经本机代理走 ChatGPT 的账号（upstream=codex，例如别名 `chatgpt`）不再出现在 list、选择器、current 和 `add` 菜单里；这只是不显示，账号数据不删除，`claudex-switch chatgpt …`、remove / rename / purge 照常可用。原生 Codex ChatGPT 账号不受影响。

`add` 菜单去掉 WorkBuddy / Antigravity / Cursor 条目上的「（本机 CLIProxyAPI）」后缀。添加后直接 `claudex-switch <别名> -run` 或 `cc` 即自动经本机代理启动，无需额外参数。

`list --json` 保持 schemaVersion 1 与全部既有字段，仍列出完整账号清单（含隐藏的 ChatGPT 代理账号），见 docs/list-json.md。

验收使用合成 HOME：四类代理账号从真实 add 菜单创建，逐一 `-run` / `cc` 共 8 条启动路径经回环接口通过；436 项测试通过。真实浏览器登录与真实上游会话未在本次验收内。
