# v1.26.1 发布说明

- `claudex-switch workbuddy --run --cliproxy claudecode` 首次使用时先选区域：国际版（workbuddy.ai，默认高亮）或国内版（workbuddy.cn）。此前裸 `workbuddy` 固定打开国内版登录页，国际版账号无法登录。选定后该别名固定使用所选版本。
- `workbuddy-ai` 仍直接使用国际版，无需选择；非交互终端运行裸 `workbuddy` 时会提示改用 `workbuddy-ai`。
- 登录提示与别名列表标明版本：`WorkBuddy (China)` / `WorkBuddy AI (international)`。

已核对两个版本的登录接口均返回 HTTPS 登录页（workbuddy.cn / workbuddy.ai）；真实国际版账号登录待用户在终端完成。
