# v1.23.3 发布说明

- 修复受管 OpenCode 会话看不到新免费模型的问题：启动前刷新模型目录，`opencode/glm-5.3-flash-free` 与 `opencode/ll-alpha-free` 现在可在 `/models` 选择。原因：私有会话此前只用 OpenCode 二进制内置目录，未收录这两个模型（`opencode/deepseek-v4.1-flash-free` 等内置免费模型不受影响）。
- 目录快照按内容哈希固定，本次启动的模型发现、路由检查与最终 TUI 使用同一份；失败保留上次有效目录，首次离线回退内置目录。
- 付费过滤、用户显式禁用的 provider / 模型与命令行默认模型（仍选 Go）不变。

# v1.23.3 release notes

- **New free native models appear in managed sessions.** Managed OpenCode V2 sessions (API-key and Console subscription) now refresh the OpenCode model catalog before model discovery, so `opencode/glm-5.3-flash-free` and `opencode/ll-alpha-free` are visible and selectable in `/models`. The private session previously kept only OpenCode's built-in catalog, which lacked them (free models that are built in, such as `opencode/deepseek-v4.1-flash-free`, are unaffected).
- The catalog snapshot is pinned by content hash for this launch's model discovery, route checks, and final TUI; a failed refresh keeps the last good catalog, and a first offline launch falls back to the built-in one.
- Paid filtering, explicit provider/model disables, and the Go CLI default model are unchanged.
