# v1.26.4 发布说明

- 修 WorkBuddy（`workbuddy` / `workbuddy-ai`）报 `API Error: 400 {"code":11101,"msg":"Non-stream chat request is currently not supported"}`。WorkBuddy 只接受流式请求，而 Claude Code 的 auto mode 分类器、标题等附带请求以及流式失败后的重试都是非流式的。本地桥现在对这类请求改发流式，再合并成一次完整回复（文本、思考内容、工具调用与用量）。Cursor 由其插件自行处理，不变。
- 订阅代理是常驻进程，升级后旧版桥会在没有会话使用时、下次启动时自动重启一次。

已核对：真实 WorkBuddy AI 账号经新桥发送非流式文本与工具调用请求，均返回完整 JSON；真实 Claude Code 2.1.309 + CLIProxyAPI 的订阅端到端脚本新增非流式请求与旧桥重启检查并通过。
