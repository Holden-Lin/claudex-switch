# 订阅默认启动原生终端

Antigravity 和 Cursor 订阅的 `--run` 现在默认启动各自的原生终端；需要 Claude Code 时，显式加 `--cliproxy claudecode` 或使用 `cc` 简写。

```bash
claudex-switch agylam42 --run                 # 启动 agy
claudex-switch my-cursor --run                # 启动 cursor agent
claudex-switch agylam42 --run --cliproxy claudecode
claudex-switch agylam42 cc                    # 同上，启动 Claude Code
```

- 原生终端使用它自己的登录态；保存的代理账号登录仅供 `--cliproxy claudecode` 使用。
- WorkBuddy 暂不支持原生终端启动。直接 `--run` 会提示改用 `--cliproxy claudecode`，不会自动切换前端。
- 新增订阅后的命令提示已同步。

验证：`env -u CLAUDE_CODE_AUTO_COMPACT_WINDOW bun run verify` 通过，528 项测试、2702 个断言、0 失败，文档检查、构建与构建产物 help 入口均通过。该变量由本机 shell 继承时会干扰既有 RelayRouter GLM 测试；发版检查显式移除它。测试覆盖原生入口参数、代理状态不创建、WorkBuddy 提示及显式 Claude Code 入口；未验证厂商模型响应或真实原生登录。沙箱禁止测试监听回环端口，完整检查在允许本地监听的环境中执行。

本机当前使用 bun 全局安装，可在本人终端升级：

```bash
bun install -g git+https://github.com/Holden-Lin/claudex-switch.git#v1.29.3
```
