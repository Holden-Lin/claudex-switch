# agy 额度只看 Gemini，codex 模型可只写数字

- `claudex-switch list` 里 Antigravity 账号的额度只显示 Gemini 模型的额度，和其他账号一样分 5 小时和每周两栏。
- `codex --model 6.1` 这样只写数字时，按 `gpt-6.1-sol` 启动。

```bash
claudex-switch list
claudex-switch satoshix -run --model 6.1 medium
```

本机升级：

```bash
claudex-switch update
```
