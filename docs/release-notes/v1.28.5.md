# RelayRouter GLM 可直接做评审会话

- `claudex-switch relayrouter -run --model glm-5.3-flash` 现在把 GLM 存为账号默认模型；私有设置的 `model` 与 `ANTHROPIC_MODEL` 一致，不再被旧的 Astra 默认值覆盖。显式 `--model gpt-6-astra` 仍可切回 Astra。
- GLM 会话按声明的 1M 上下文窗口运行并相应设置压缩阈值，small-fast 模型同为 GLM。
- 只随 RelayRouter 会话启停的兼容层修正了工具调用历史（thinking-only 历史、工具结果保留），GLM 可完成工具调用后的后续回复。
- 实测三次共花费 $0.004674；484 项测试通过。
