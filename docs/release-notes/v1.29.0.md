# 查看 Claude Fable 剩余周额度

- `claudex-switch list` 在 Claude API 返回 Fable 专属周窗口时，追加 `fable 58% Sun16`，显示剩余额度及本地时区重置时间；现有 `wk` 格式保持不变。
- `list --json` 的 `usage` 追加可选字段 `fableWeeklyUsedPercent` 和 `fableWeeklyResetsAt`，分别为已用百分比与重置时间戳（毫秒）；API 未返回 Fable 窗口时省略。
- 当前用量 API 不提供 full reset / Fable reset 剩余次数，因此不显示次数，也不按每周额度的 50% 推算 Fable 剩余额度。
- 514 项测试通过，覆盖 Fable 窗口、缓存与列表输出，以及超过 100% 的原有周用量仍显示 `wk 0%`。
