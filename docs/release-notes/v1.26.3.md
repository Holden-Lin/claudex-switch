# v1.26.3 发布说明

- WorkBuddy（`workbuddy` / `workbuddy-ai`）的 auto mode 权限分类器默认改用 `deepseek-v4.1-flash`。此前分类器跟随 sonnet 档位，落到 WorkBuddy 的 Auto（积分倍率未公布、窗口 176K），每次判定工具调用都会请求一次。
- 只写入该账号 `--run --cliproxy claudecode` 的私有设置文件：主模型仍由 Claude Code 选择，普通 Claude Code、全局 `~/.claude/settings.json` 及其他账号不受影响。账号目录没有该模型时不设置；在账号自定义 env 中设置 `CLAUDE_CODE_AUTO_MODE_MODEL` 可覆盖。

已用真实 Claude Code 2.1.309（含非 `--bare` 模式）核对：主模型为 kimi-k2.6 时，分类请求全部发往 deepseek-v4.1-flash。
