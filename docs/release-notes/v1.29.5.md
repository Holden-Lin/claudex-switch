# agylam42 等 Antigravity 别名不再误报 invalid config

agylam42 等 Antigravity 别名不再被误报 `invalid config`，`claudex-switch doctor <别名> --restart` 也能正常重建（CLIProxyAPI 8.x 启动后会在配置文件末尾追加 `server-id`，之前被误判为配置漂移）。

```bash
claudex-switch doctor agylam42 --restart
claudex-switch list   # agylam42 不再显示 invalid config
```

本机升级：

```bash
claudex-switch update
```

发布地址：[v1.29.5](https://github.com/Holden-Lin/claudex-switch/releases/tag/v1.29.5)。
