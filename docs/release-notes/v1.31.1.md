# 启动参数统一为 `--run`；别名表和 Codex 账号表自动备份

- 启动只认 `--run`（两个杠）；命令里重复写的启动参数会被正确吃掉，不再把一个杠的 `-run` 传给下游工具。
- 写别名表和 Codex 账号表前自动留备份（`~/.claudex-switch/backups/`，各保留最近 20 份）。
- 测试和探针不能再写进真实 HOME（11-26 别名表被评审探针覆盖的事故）。

```bash
claudex-switch satoshix --run --model 6.1 medium
```

本机升级：

```bash
claudex-switch update
```
