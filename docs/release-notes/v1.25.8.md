# v1.25.8 发布说明

- 修复 `claudex-switch agy --run --cliproxy claudecode` 仍报 `400 unknown provider for model claude-opus-5-5`。原因：CLIProxyAPI 启动时先返回内置旧目录（无 Opus 5.5），数秒后才换成远程目录；旧版只取第一份，默认停在已停用的 Opus 4.6，`/model` 保存的 `claude-opus-5-5` 也没有映射。现在新启动的代理会等目录稳定（最多 12 秒）。
- 已停用的 Claude 版本（Opus / Sonnet 4.6 只回复 "no longer available"）不再进入 `/model` 菜单。仍指向它们的档位改到同系列最新版。
- Claude Code 自己的模型 ID 和共享 `settings.json` 里保存的 `/model` 默认值会映射到代理的真实 ID，例如 `claude-opus-5-5 → claude-opus-5-5-high`、`claude-haiku-5-5 → gemini-3.8-flash-high`。

真实 Claude Code 2.1.308 + CLIProxyAPI 7.3.20 已验证：保存默认 `claude-opus-5-5` 时，旧配置重现截图里的 400，新配置能正常对话，Read 工具两轮调用也能完成。升级后需先结束正在用 agy 的旧会话，再重新运行。
