# v1.24.0 发布说明

- `list` 底部新增近 30 天走势图：每天一格的 token 用量（本机 Claude Code / Codex / OpenCode 会话日志合计，含缓存读写）与源码新增行数（这些会话所在 git 仓库中、作者为该仓库 `user.email` 的提交；只计源码文件，排除 output / data / logs 等产出目录），附总量、峰值日与仓库数。
- 统计由后台刷新进程计算（最多每 10 分钟一次，本机实测约 3 秒），结果写入 `~/.claudex-switch/activity-cache.json`；`list` 与 `list --cached` 只读缓存，启动速度不变。`--json` 输出不变。

# v1.24.0 release notes

- **30-day trend under `list`.** One column per day for tokens (local Claude Code / Codex / OpenCode session logs, cache reads and writes included) and committed source lines (commits by each repo's `user.email` in the git repos those sessions ran in; source files only, output / data / logs directories excluded), with totals, the peak day, and the repo count.
- The background refresher computes it at most every 10 minutes (about 3 seconds on a heavy machine) into `~/.claudex-switch/activity-cache.json`; `list` and `list --cached` only read the cache, so startup speed is unchanged. `--json` output is unchanged.
