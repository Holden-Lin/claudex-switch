# v1.27.0：代理账号管理与 Claude 独立设置

`claudex-switch add <alias>` 可直接添加 WorkBuddy（国际版 / 国内版）、Antigravity（agy）和 Cursor，复用原有登录流程。旧的首次运行创建路径继续可用。

代理账号支持全局切换：`claudex-switch workbuddy` 与 `use workbuddy` 会启动或复用代理，让裸 `claude` 使用该账号；切回 OAuth 会清除代理管理的环境变量并恢复账号凭据。代理后台进程会在切换命令退出后继续运行，代理停止时连接报错，不自动换账号。

Claude OAuth、API Key 和代理的 `-run` 使用私有用户设置；原来的共享设置链接会自动迁移。全局切换不会改变已有独立会话的路由或模型，独立会话里的 `/model` 也不会改变全局默认。技能、hooks 和 CLAUDE.md 继续可用。

`claudex-switch agy cc` 是 `agy -run --cliproxy claudecode` 的快捷写法。其他未知尾随参数直接报错，`<alias> --help` / `-h` 仍只显示帮助。

补齐 Claude Code 2.1.316 auto 分类器实际请求的 `claude-sonnet-5` 映射，避免 agy 分类请求使用目录外的模型。另一台电脑的版本、权限设置和模型组额度仍可能造成 auto 不可用；检查步骤见[本机代理说明](../local-cliproxyapi.md#agy-的-auto-模式不可用)。

验证：437 项测试、类型 / 文档检查与构建通过；临时 HOME 的打包 CLI 完成各类型添加、全局切换与 OAuth 恢复、独立会话重载与设置写入隔离。真实 Claude Code 2.1.316 配合假 agy 上游验证 Opus / Gemini auto 分类成功，禁止 auto 的设置仍生效。没有读取真实凭据或切换真实全局账号。
