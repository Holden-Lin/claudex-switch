# v1.17.0 release notes

These notes describe the v1.17.0 feature set. Check the [GitHub releases page](https://github.com/Holden-Lin/claudex-switch/releases) for current availability.

- OpenCode Go V2 `add` / `refresh` can now explicitly import a Go login already stored in local OpenCode's SQLite database (the active `opencode-go` credential first; other providers are never exported), or accept a manually pasted masked API key. This keeps the first alias one keystroke away for a new user who already logged into OpenCode.
- The chosen key is verified against the same OpenCode Go usage endpoint `list` uses before it is saved: 401 (invalid key) and 403 (no Go subscription) are rejected and the prompt repeats, while an unreachable server still allows saving after a warning. A typo can no longer silently create an alias that fails only on its first model request.
- `refresh` keeps rejecting an unchanged key. `add` now prints the first-run model requirement for V2 aliases (`-run --model opencode-go/<model>`).
- V1 behavior, V2 launch isolation, quota display, and all other providers are unchanged.
