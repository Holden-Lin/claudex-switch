# v1.26.0

Claude Code 可以使用 WorkBuddy、WorkBuddy AI 和 Cursor 订阅：

```bash
claudex-switch workbuddy --run --cliproxy claudecode
claudex-switch workbuddy-ai --run --cliproxy claudecode
claudex-switch cursor --run --cliproxy claudecode
```

首次选择登录方式。独立插件随程序分发，无需安装 magpie；模型从账号目录获取，`/model` 保留可用版本，工具调用与流式回复经过现有本地代理。浏览器登录保存独立凭据；沿用原应用登录会跟随其账号切换。`refresh` 核验账号，使用中的会话阻止刷新与删除。

本地转换代理默认设置 `CLAUDE_CODE_AUTO_MODE_SERVER=0`，按官方方式使用客户端分类器，处理网关不兼容服务端分类器的提示。auto mode 保持可用，客户端分类请求仍计入用量。此项不解决 Antigravity 的 `429 / Individual quota reached`，配额需等待重置。

已用真实 Claude Code、CLIProxyAPI 和 WorkBuddy 插件配合合成上游验证两轮 Read 工具回环；此证据不代表真实订阅授权及额度已验证。
