# agy 别名 `--run` 使用该别名自己的账号

`claudex-switch <agy 别名> --run` 现在启动原生 agy 时，使用该别名保存的账号（经其自己的 CLIProxyAPI 网关），不再落到之前的旧账号。

```bash
claudex-switch agylam42 --run   # 使用 agylam42 自己的账号
```

验证：`bun run verify` 530 项通过、1 项失败；唯一失败是 main 上已存在的 RelayRouter GLM 持久化测试（已记入 TODO），与本次无关；构建与构建产物 help 入口通过。本次只改版本号与发布说明，不改功能代码；未验证真实厂商登录。

本机升级：

```bash
claudex-switch update
```
