# AGY 别名使用独立原生 profile

`claudex-switch <agy别名> --run` 直接打开官方 `agy`。每个账号的原生 profile 保存自己的登录、设置和会话。首次启动时在 Google OAuth 界面选对账号，后续直接复用该登录。

```bash
claudex-switch agylam42 --run
claudex-switch agy --run --model gemini-4-neon xhigh
```

进入后用 `/usage` 看订阅额度，用 `/model` 保存该 profile 的默认模型。显式 `cc` 或 `--cliproxy claudecode` 仍使用已有的代理登录。

独立目录和文件凭据来自 `agy` 的未公开接口，在 agy 1.5.17 上已核对。536 项本地测试通过，真实 CLI 在隔离 HOME 已打开独立 OAuth 登录页。
