# v1.25.1 发布说明

- 修复 `claudex-switch agy --run --cliproxy claudecode` 报 `Unknown command: "agy"`：命令分发只在别名已存在时才转入运行路径，而 `agy` 首次使用要由代理解析器自建别名，故永远走不到解析器。现在带 `--cliproxy` 的运行命令即使别名不存在也会进入代理解析器；未知名报 `Alias "x" not found.` 而非未知命令。漏掉 `--cliproxy` 时提示正确的代理命令。

# v1.25.1 release notes

- **Fixed `Unknown command: "agy"` on the first Antigravity run.** The dispatcher only sent a command to the run path when the alias already existed, but `agy` creates its own alias on first use through the proxy resolver, so the command never reached that resolver. A run command carrying `--cliproxy` now always reaches the proxy resolver, even when the alias does not exist yet; an unknown name is reported as `Alias "x" not found.` instead of an unknown command. Leaving out `--cliproxy` now points at the correct proxy command.
