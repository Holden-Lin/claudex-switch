# v1.14.0 release notes

These notes describe the v1.14.0 feature set. Check the [GitHub releases page](https://github.com/Holden-Lin/claudex-switch/releases) for current availability; v1.13.2 does not support `--json`.

- Add `claudex-switch list --json --no-usage`, a schema-versioned, allowlisted local inventory. In this mode the command makes no quota requests, refreshes no credentials, switches no accounts, and does not synchronize the active Codex auth snapshot. Aliases remain user-chosen and may identify an account.
- Add bilingual setup, provider-boundary, FAQ, and JSON reference docs, plus an optional repository skill source. The skill is not automatically installed or guaranteed to be discovered; users must opt in through a skill directory supported by their agent.
- Fixture tests cover deterministic JSON, omission of credential and endpoint sentinels, missing or malformed profile data, and no-network/no-write behavior for offline JSON. These tests do not exercise live provider authentication or guarantee behavior for every external service response. Released v1.13.2 does not support `--json`.
