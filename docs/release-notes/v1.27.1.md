# v1.27.1：独立会话每次启动同步共享设置

修复 v1.27.0 的私有用户设置只复制一次的问题。OAuth、API Key、代理账号每次 `-run` 都从当前共享 `settings.json` 重建私有副本，再应用账号自己的路由和配置。后来安装的 hooks、permissions、autoMode 规则和用户键会进入下一次启动；已经转成普通私有文件的账号也会自动修复。

会话内 `/model` 或其他用户设置写入仍不会修改共享文件，重启时丢弃。通过 `claudex-switch model` / `webconfig` 保存的账号配置继续保留；技能、CLAUDE.md 和项目配置发现保留。

验收使用合成 HOME，覆盖共享设置后续更新、会话写入隔离、旧私有文件刷新，以及 v1.27.0 的路由键覆盖和全局切换隔离。
