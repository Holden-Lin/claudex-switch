# agy 原生终端终于用上你指定的模型

`claudex-switch <agy别名> --run` 现在会真正使用你选的模型：

- 不带 `--model` 时，用该账号保存的模型。
- `--model gemini-4-neon xhigh`、`--model "gemini-4-neon xhigh"`、`--model gemini-4-neon-high --effort xhigh` 都会换成账号里的 `gemini-4-neon-xhigh` 再启动，不再报 `unexpected argument "xhigh"`，也不会被 agy 换成别的模型。
- 账号里没有的档位直接报错，并列出可选档位。
- Gemini 带档位的模型（如 `gemini-4-neon-xhigh`、`gemini-3.8-flash-high`）不再报 `400 unknown provider for model gemini-4-neon`：agy 走代理时会去掉档位后缀，现在本地代理会把去掉后缀的名字转回原模型。已在运行的代理会自动加载，不用重启。
- agy 启动时的模型显示不再偶尔停在 `~/.gemini/antigravity-cli/settings.json` 里存的旧模型；这个文件本身不会被改动。

```bash
claudex-switch agylam42 --run
claudex-switch agy -run --model gemini-4-neon xhigh
```

本机升级：

```bash
claudex-switch update
```
